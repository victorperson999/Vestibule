## 5. The README's new lines

**Alt text:** Terminal recording. A short program runs twice. On the machine itself it reads
a fake key file and connects to 1.1.1.1. Run through Vestibule, the same program reports "No
such file or directory" for the file and "Network is unreachable" for the connection, and the
result ends with "isolation: native".

**Caption:** *A real Claude Code session in Ubuntu under WSL2, recorded on 2026-11-11 with a
development install of 0.1.1's code and the flags of the stricter line from "What is and
isn't sandboxed" (the existing link, unchanged), so `run_code` was the agent's only way to
run code. A fake key is planted on the machine. The same short program runs first on the
machine itself and then through Vestibule: it tries to read the key and to open a connection
to 1.1.1.1, and prints one line for each. It sends nothing. Claude Code folds tool results,
so the agent was asked to repeat the result, and its copy matches the tool's result exactly.
Edits: Claude Code's start-up banner and the pasting of the prompt are cut, the end of the
session after the result is dropped, and the last frame is held. `native` needs a Linux that
allows unprivileged user namespaces, as WSL2 does. An install on Windows itself with Docker
Desktop, or on stock Ubuntu 24.04 with Docker Engine from Docker's apt repository, gets
`isolation: container`, and macOS is expected to.*

**What the GIF does and doesn't show:** that this run couldn't see a file outside the
workspace and had no network. It doesn't show that nothing can leave: a run's output goes
back to the agent, as "What it protects, and what it doesn't" says a few sections down. The
GIF makes no statement about that either way, now that the agent's sentence is gone.
